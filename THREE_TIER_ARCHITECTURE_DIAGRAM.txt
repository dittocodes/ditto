================================================================================
                              DATA FLOW DIAGRAM
================================================================================

1. USER AUTHENTICATION FLOW:
   User Login → Frontend → API Gateway → Authentication Service → JWT Token → Session Storage

2. DATA ACCESS FLOW:
   Frontend Request → API Gateway → Business Logic → Database Query → Cache Check → Data Return

3. FILE UPLOAD FLOW:
   File Upload → Frontend → API Gateway → File Service → AWS S3 → URL Return

4. AI INTEGRATION FLOW:
   Competency Data → AI Service → Google Gemini → Analysis → Report Generation → Database Storage

5. EMAIL NOTIFICATION FLOW:
   Event Trigger → Email Service → ZeptoMail → SMTP → User Email

================================================================================
                              SCALABILITY FEATURES
================================================================================

┌─────────────────────────────────────────────────────────────────────────────────┐
│                              SCALABILITY ARCHITECTURE                           │
└─────────────────────────────────────────────────────────────────────────────────┘

• AUTO-SCALING: AWS Lambda automatically scales based on demand
• LOAD BALANCING: API Gateway distributes requests across multiple instances
• CACHING: Redis cache reduces database load and improves response times
• CDN: CloudFront serves static assets globally with low latency
• DATABASE: RDS supports read replicas for horizontal scaling
• STORAGE: S3 provides unlimited scalable storage
