================================================================================
                                EXECUTIVE SUMMARY
================================================================================

The Mentee Tracker MCA is a comprehensive web-based mentorship management system 
designed for educational institutions. The application implements a modern three-tier 
architecture with separate presentation, business logic, and data layers. It supports 
three user roles: Students, Mentors, and Administrators, providing features for 
mentorship tracking, competency assessment, activity management, and AI-powered 
observation generation.

Key Features:
- Multi-role user management (Student, Mentor, Admin)
- Mentorship activity tracking and approval workflow
- Psychometric assessment and competency evaluation
- AI-powered observation generation using Google Gemini
- Meeting scheduling and management
- Report generation with radar charts
- MCA (Mentorship Competency Assessment) system
- Email notifications and file storage via AWS S3

================================================================================
                            THREE-TIER ARCHITECTURE OVERVIEW
================================================================================

TIER 1: PRESENTATION LAYER (Frontend)
├── Technology: React.js 19.0.0
├── Routing: React Router DOM 7.1.1
├── State Management: React Hooks + Session Storage
├── UI Components: Custom CSS + React Icons
├── HTTP Client: Axios
├── Charts: Recharts 2.15.1
└── File Handling: XLSX 0.18.5

TIER 2: BUSINESS LOGIC LAYER (Backend)
├── Framework: FastAPI (Python)
├── Authentication: JWT with python-jose
├── Database ORM: SQLAlchemy
├── AI Integration: Google Generative AI (Gemini 2.0)
├── Cloud Services: AWS S3, AWS Lambda
├── Email Service: SMTP (ZeptoMail)
├── Background Tasks: APScheduler
├── PDF Generation: ReportLab
└── Data Visualization: Matplotlib, Seaborn

TIER 3: DATA LAYER (Database)
├── Database: MySQL (AWS RDS)
├── Connection: PyMySQL
├── ORM: SQLAlchemy with declarative base
├── Caching: Redis (configured)
└── File Storage: AWS S3
