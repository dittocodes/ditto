   └── STANDARD: Industry-standard authentication method

   ┌─────────────────────────────────────────────────────────────────────────────┐
   │                             BCRYPT EXPLANATION                              │
   └─────────────────────────────────────────────────────────────────────────────┘
   
   What is bcrypt?
   bcrypt is a password hashing function designed by Niels Provos and David 
   Mazières, based on the Blowfish cipher. It's specifically designed for 
   password hashing and includes a salt to protect against rainbow table attacks.
   
   Why bcrypt in this project?
   ├── SECURITY: Industry-standard password hashing
   ├── SALTING: Automatic salt generation for each password
   ├── ADAPTIVE: Configurable work factor for future-proofing
   ├── SLOW: Designed to be computationally expensive
   ├── PROVEN: Battle-tested security algorithm
   └── COMPLIANCE: Meets security standards and regulations
   
   Implementation in MENTEE_TRACKER_MCA:
   ├── Student password hashing
   ├── Mentor password hashing
   ├── Admin password hashing
   ├── Secure password verification
   ├── Password reset functionality
   └── Security compliance
